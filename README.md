# Healthcare Data Analysis & Interactive Dashboard

## Project Overview
An end-to-end healthcare data analysis project focused on exploring diabetes prevalence and identifying relationships between various health and lifestyle indicators.

## Objectives
- Analyze diabetes prevalence across different age groups.
- Study the relationship between BMI and diabetes.
- Investigate blood pressure and cholesterol patterns.
- Examine the relationship between physical activity and diabetes.
- Develop an interactive healthcare analytics dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit

## Key Analysis
1. High Blood Pressure Analysis
2. High Cholesterol Analysis
3. BMI Analysis
4. Physical Activity Analysis
5. Age Group Analysis

## Dashboard Features
- Interactive data filters
- Healthcare KPI metrics
- Diabetes distribution charts
- BMI and risk-factor analysis
- Age-group visualization
- Filtered dataset export

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd Healthcare-Data-Analysis
pip install -r requirements.txt
streamlit run app.py
```
